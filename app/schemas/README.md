# Room schemas

Room writes the exported database schema here as JSON, one file per database
version, during an Android build (`club.hiraeth.flareenough.data.db.FlareDatabase/1.json`
and so on).

These files are the record of each schema version. They let migration tests run
against a known past schema, and they should be committed once generated.

They are generated by the Android build (Android Studio or CI), so they are not
present until the app has been built at least once on a machine with the Android
SDK.
